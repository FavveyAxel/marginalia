## Nouveautés

- **Combien de personnes ?** En ouvrant une session « Travailler à plusieurs », l’hôte choisit de 2 à 6 personnes (lui compris). Le nombre se change pendant la session, sans jamais descendre sous le nombre de présents. Session complète : la demande suivante est refusée avec un message clair.
- **« Copier le code ».** Sous le code de la session, un bouton copie le code pour l’envoyer par message, par exemple à quelqu’un qui rejoint par Internet. Collé dans « Rejoindre », il est reconnu tel quel.

## Corrections

- **Les boutons « Copier » fonctionnent de nouveau** (citations du lecteur, arguments, livre papier) : l’app refusait l’écriture dans le presse-papiers.
- **Plusieurs demandes en même temps** : les cartes s’empilent et restent dans l’écran, avec défilement s’il y en a beaucoup.

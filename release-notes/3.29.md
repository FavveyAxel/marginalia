## Nouveautés

- **Mises à jour automatiques** : à partir de cette version, les nouvelles versions de Marginalia se téléchargent en arrière-plan. Une fois prête, « Redémarrer pour mettre à jour » l’installe tout de suite ; sinon, elle s’installe à la fermeture de l’app. Vos livres, notes et écrits sont conservés, et « Quoi de neuf » montre ce qui a changé.
  - Chaque version est signée : Marginalia vérifie la signature et l’empreinte du fichier avant d’installer quoi que ce soit, et refuse un fichier modifié.
  - Réglages › Mises à jour : « Installer automatiquement » ou « Me demander ». La vérification reste désactivable ; aucune donnée n’est envoyée.
  - Sur Mac, Marginalia doit être dans le dossier Applications pour se mettre à jour seule ; sinon, elle propose la page de téléchargement.

## Installer

Cette fois encore, téléchargez la version pour votre ordinateur sur [le site de Marginalia](https://marginalia-bice.vercel.app/#telecharger) et installez-la par-dessus l’ancienne : vos données sont conservées. Les versions suivantes s’installeront toutes seules.

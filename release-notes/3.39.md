## Corrections

- **Windows : l’app s’ouvre au premier clic.** Il fallait parfois cliquer deux fois sur l’icône, le raccourci ou un élément récent : la fenêtre restait cachée. Elle s’affiche maintenant à chaque lancement.
- **Windows : l’app se rouvre après une mise à jour**, au premier plan, même si l’ancienne version met un instant à se fermer.
- **« Envoyer une copie » : le code vaut maintenant deux minutes**, pour laisser le temps à une connexion lente.
- **La fenêtre « Envoyé » s’affiche correctement** : elle défilait, et l’illustration des deux ordinateurs était tassée dans un coin.
- Fermeture plus propre quand une session par Internet est ouverte.

## Installer

Avec la 3.29 ou plus récente, cette version se télécharge depuis l’app. Sur Windows, si l’app ne se rouvre pas d’elle-même après cette mise à jour, ouvrez-la une fois : les suivantes se feront normalement. En 3.36 ou avant, installez-la depuis [le site de Marginalia](https://marginalia-bice.vercel.app/#telecharger).

# Sons de la machine à écrire

Enregistrements d'une Hermes Precisa 305 par Joseph Sardin, publiés sur BigSoundBank.com
sous licence CC0 (domaine public : usage commercial et redistribution permis, sans obligation
de crédit).

| Fichiers | Source BigSoundBank |
| --- | --- |
| `key1` à `key8`, `space2` à `space5`, `return1`, `return2`, `back` | « Typewriter 2 », nº 2835 |
| `key9` | « Typewriter key », nº 2842 |
| `space1` | « Typewriter space », nº 2843 |
| `bell` | « Typewriter bell », nº 2844 |

Traitement : passage en mono 44,1 kHz 16 bits, découpe de frappes isolées, fondu de sortie,
niveaux égalisés. `back` est une frappe ralentie et atténuée ; les retours chariot sont
raccourcis (levier, puis butée).

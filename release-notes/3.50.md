## Correction

- **Déplacer un document vers un autre espace.** Clic droit sur un document › « Déplacer vers… » : la fenêtre propose maintenant tous vos espaces, l’actuel en premier, chacun avec ses groupes. Jusqu’ici, elle ne montrait que l’espace où se trouvait déjà le document.

## Installer

Cette version se télécharge depuis l’app. Sur Windows, si vous êtes encore en 3.36 ou avant, installez-la une fois depuis [le site de Marginalia](https://marginalia-bice.vercel.app/#telecharger).

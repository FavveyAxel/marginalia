## Nouveautés

- **Renommer un document.** Dans la bibliothèque, clic droit sur un livre, un PDF, une vidéo ou une image → « Renommer », ou la touche F2 sur le document sélectionné au clavier. Dans un espace, « Renommer » est aussi proposé sur un écrit ou un plan, dans la vue de l’espace comme dans la barre latérale.
- Le titre change dans Marginalia ; le fichier d’origine sur votre disque garde son nom. Les autres champs (auteur, édition) restent dans « Infos et édition ».

## Installer

Cette version se télécharge depuis l’app. Sur Windows, si vous êtes encore en 3.36 ou avant, installez-la une fois depuis [le site de Marginalia](https://marginalia-bice.vercel.app/#telecharger).
